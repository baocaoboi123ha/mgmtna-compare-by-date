# MGMTNA Compare By Date (web)

Streamlit app công khai, không đăng nhập. Chọn **phiên bản 7.0 / 8.0 / 9.0** ở dropdown trên header trước khi chạy đối chiếu.

| Phiên bản | File kết quả | Ghi chú |
|-----------|--------------|---------|
| 7.0 | `… - ByDate 7.0.xlsx` | Layout 4.0, bảng Unit cơ bản |
| 8.0 | `… - ByDate 8.0.xlsx` | Qty thực tế, công thức quy đổi, viền bảng |
| 9.0 | `… - ByDate 9.0.xlsx` | Như 8.0 + list mã thiếu Unit một bên (BC hoặc TP) |

Deploy: [Streamlit Community Cloud](https://share.streamlit.io/) từ repo GitHub `baocaoboi123ha/mgmtna-compare-by-date`.
